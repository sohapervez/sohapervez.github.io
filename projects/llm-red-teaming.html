AI Safety Research

LLM Red-Teaming Toolkit

n8n Python 3.10+ Ollama OpenAI API asyncio LangChain
Research use only. This toolkit is designed for authorised safety evaluation in controlled environments. It is not intended for use against third-party systems without permission. This page shows the evaluation pipeline only — actual test prompts and model outputs are not displayed here.

The Problem

Evaluating how robustly an LLM handles adversarial inputs was a manual, inconsistent process. Researchers needed a systematic way to probe models, score their responses against safety criteria, and generate varied attack variants — all without relying on human judgment for every test case.

What I Built

A two-stage build: a no-code n8n prototype to validate the pipeline concept, then a full Python toolkit for reproducible, scriptable evaluation.

Stage 1 — n8n Prototype

A visual automation workflow that sends paraphrased adversarial prompts to 4 LLMs in parallel batches, checks each reply with an "Is jailbroken?" evaluator node, merges the results, and generates a PDF summary report — showing which models were jailbroken and on which attempt. Building in n8n first let me validate the logic end-to-end without writing a line of code.

Stage 2 — Python Toolkit

The same pipeline rebuilt in Python (VS Code) for full programmatic control, composability, and async performance:

  • jailbreaking.py — loads test prompts, queries a target model via an Ollama or OpenAI-compatible endpoint, and scores each response using 6 heuristic signals: refusal language detection, response length analysis, specificity markers, keyword signals, and more. Testing halts on first successful jailbreak detection.
  • adversarial_prompts.py — generates prompt variants through 6 transformation methods: paraphrase, obfuscate, roleplay, injection_suffix, concat_suffixes, translate_roundtrip. Outputs timestamped JSON to outputs/ for reproducible analysis.

Functions are designed to be importable and composable — the toolkit slots into larger evaluation workflows or CI pipelines.

The Result

A reproducible, automated way to benchmark LLM robustness across model versions and prompt strategies. Each run produces structured JSON output with per-prompt scores, enabling trend analysis as models are updated. The framework surfaced systematic refusal failures that would have been missed by manual spot-checking.
