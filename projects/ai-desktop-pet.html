Desktop App · AI Chat

AI Desktop Pet

Tauri Rust TypeScript Node.js

The Problem

Desktop companion apps were either too distracting (always on top, blocking work) or too dumb (no AI, same static messages). There was no companion that stayed out of the way, sent genuinely useful wellness nudges, and could hold a real conversation — all without requiring an internet connection or an account.

What I Built

A cross-platform desktop pet built with Tauri — a Rust + TypeScript framework that bundles apps at near-native performance without shipping a full browser engine. The pet lives at the edge of your screen and is out of the way until you need it:

  • Click-through transparency — the pet window lets all mouse events pass through to the app behind it, so it never blocks work. The polling loop runs at ~60fps.
  • Summon button — a draggable pink button on the screen edge that slides the pet in and out. Drag it to wherever works best.
  • Smart wellness reminders — Rust-backed scheduler sends timed nudges for water, breaks, and stretching. Reminders can be paused (30 min / 1 hr / until tomorrow) from the system tray.
  • Offline chat mode — the pet understands greetings, mood signals, and reminder keywords with no internet needed. Warm and short replies by default.
  • AI chat mode — optional OpenAI integration for natural conversation. The API key is stored only on the device, never sent elsewhere. The personality prompt is user-editable via config/personality.json.
  • Custom sprites — animated frame sequences (idle, walk, blink, enter, leave) loaded from assets/sprites/. Ships with a programmatic placeholder character.
  • System tray — full control from the tray: settings, pause, resume, reset pet position, quit.

Technical Highlights

  • Transparent, always-on-top windows use a private macOS API — works on macOS 10.15+ but cannot be App Store distributed
  • Rust backend handles all Tauri commands, the visit/water scheduler, tray menu, and window creation
  • TypeScript windows (pet, summon button, chat, settings) communicate via Tauri IPC
  • Builds to a .dmg (macOS) or .exe installer (Windows) with npm run tauri build

The Result

A fully working, installable desktop companion that runs at native performance — no Electron, no bundled Chromium, no noticeable CPU overhead during normal use. The offline chat makes it usable without any accounts or API keys, while the OpenAI integration unlocks richer conversations for those who want it.
